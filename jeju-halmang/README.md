# 할망의 한 동 — 제주 인터랙티브 스토리 미디어아트

설문대할망 신화(흙으로 제주를 빚음 → 명주 백 동 중 한 동이 모자람)를 관람자가 직접 만지며 완성하는 웹 작품입니다.

## 관람 흐름
1. **태초** — 귀를 기울일지, 바라볼지 선택 (시작 분위기·색이 달라짐)
2. **오름** — 바다를 눌러 흙을 부어 오름 5개 → 한라산 (터치/클릭 인터랙션)
3. **소원** — 바람·물·불·돌 중 선택 (화면 연출과 서사가 달라짐)
4. **명주** — 꾹 눌러 99동을 잇지만 한 동이 모자람
5. **한 동** — 관람자가 한 단어를 건네면 그 단어로 장면이 지어지고, 금실이 되어 화면에 걸림. 이야기 카드 PNG로 저장 가능

## AI 연동
- 기본(AI 미연결): 단어의 정서를 분류해 이야기 조각을 엮는 로컬 생성. 화면에 "AI 미연결 모드"라고 표시됩니다.
- Claude 연결: `server/scene.js`를 Vercel 등에 배포(`ANTHROPIC_API_KEY` 설정) 후 `index.html`의 `CONFIG.endpoint`에 주소를 넣습니다. API 키는 브라우저에 노출되지 않습니다. (실제 키로는 아직 테스트되지 않음)

## 실행/배포
- 로컬: `index.html`을 브라우저로 열기
- 배포: `main`에 푸시 → GitHub Actions가 GitHub Pages로 배포 (`/jeju-halmang/`)

※ 구전을 바탕으로 재구성한 이야기입니다.
